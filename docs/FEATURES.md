# Features Overview

## 🔐 Authentication & User Management
- **Login/Register**: Secure authentication flows.
- **Protected Routes**: Middleware-like protection for sensitive routes (e.g., Profile, Upload).
- **Profile Management**: Users can view and edit their profiles.

## 👨‍🏫 Tutor Platform
- **Be a Tutor**: Application flow for users to become tutors.
- **Tutor Discovery**: Browse and search for tutors (`/tutors`).
- **Tutor Profiles**: Detailed view of tutor qualifications and offers (`/tutor/$id`).
- **Posts**: Tutors can create posts to engage with students.

## 📚 Learning Resources
- **Mini Lessons**: Short educational content for quick learning (`/mini-lessons`).
- **Upload System**: Tutors can upload new mini-lessons (`/mini-lessons/upload`).
- **For Parents**: Dedicated section for parent resources and guides.

## 🌐 General Features
- **Feed**: Main landing page showing relevant content.
- **Support**: Help center and support resources.
- **Legal**: Privacy Policy and Terms of Service pages.
- **Internationalization**: Built-in i18n support.
