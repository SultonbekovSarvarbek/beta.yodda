# Insoday

A modern tutoring and learning platform built with React 19 and TanStack Router.

## 🚀 Quick Start

```bash
# Install dependencies
yarn install

# Start development server
yarn dev
```

## 📖 Documentation

- [**Features**](./docs/FEATURES.md): Overview of application capabilities (Tutors, Mini Lessons, Auth).
- [**Architecture**](./docs/ARCHITECTURE.md): Tech stack, routing, and state management details.
- [**Development**](./docs/DEVELOPMENT.md): Setup guide, scripts, and coding conventions.

## 🛠 Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, shadcn/ui
- **Routing**: TanStack Router
- **State**: Zustand, TanStack Query

## 🧪 Testing

```bash
yarn test
```
